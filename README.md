# Calculadora de IMC

Exercício de JavaScript para praticar formulários, validação de entrada e atualização do DOM.

## Funcionalidades

- entrada de altura e peso;
- validação de valores;
- cálculo e classificação simples do IMC;
- interface responsiva;
- resultado anunciado de forma acessível.

## Rodando localmente

```bash
git clone https://github.com/Santoszoi/calculadoraimc.git
cd calculadoraimc
python -m http.server 8000
```

Acesse `http://localhost:8000`.

## O que pratiquei

Validação de formulários, conversão numérica, eventos de submit e atualização segura de conteúdo com `textContent`.

> Exercício educacional. O resultado é apenas informativo e não substitui avaliação profissional de saúde.
